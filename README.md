# Aplicación de Gestión de Gastos Personales

Este proyecto fue desarrollado como parte de una asignatura sobre diseño de interfaces. Consiste en una aplicación de escritorio para la gestión de gastos personales, implementada en Java utilizando el entorno de desarrollo NetBeans y SceneBuilder para el diseño de la interfaz gráfica.

## Características

- Registro manual de gastos con descripción y cantidad
- Clasificación básica por categorías
- Interfaz gráfica sencilla e intuitiva (JavaFX + SceneBuilder)
- Estilizado con CSS para una mejor experiencia visual

## Tecnologías utilizadas

- Java
- JavaFX
- SceneBuilder
- CSS
- NetBeans
